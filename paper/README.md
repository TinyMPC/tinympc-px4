# Workshop extended abstract draft

`sustainable_tinympc_px4_extended_abstract.html` is the editable two-page
Track 1 manuscript source. The checked-in PDF uses 11-point body text on US
letter paper.

Render it with Python 3 and ReportLab:

```bash
python3 paper/render_extended_abstract.py
```

Before submission, confirm the workshop name, author affiliations, email,
coauthor list, and final artifact URL. The draft describes SITL evidence and
must not be presented as hardware validation or a general claim that TinyMPC is
better than the complete PX4 flight stack.
